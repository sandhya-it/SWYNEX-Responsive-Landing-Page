# ✈️ Comfy Travels — Discover the World in Comfort

Comfy Travels is a modern travel and tourism landing page designed to inspire travelers to explore beautiful destinations and discover memorable experiences. Featuring a clean, minimal, and luxurious interface, the platform delivers a seamless and responsive experience across devices.

## 🌍 Features

- **Destination Discovery** — Explore inspiring travel destinations.
- **Modern Landing Page** — Enjoy an elegant layout with visually engaging sections.
- **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- **Interactive UI** — Smooth navigation and engaging interface elements.
- **Travel Inspiration** — Discover ideas for holidays and memorable getaways.
- **Reusable Components** — A structured frontend architecture for maintainability.

## 🛠️ Tech Stack

- **React** — Component-based user interface development.
- **TypeScript** — Type-safe and maintainable application code.
- **Vite** — Fast development server and build tooling.
- **Tailwind CSS** — Utility-first styling for responsive layouts.
- **Git & GitHub** — Version control and source code management.
- **Vercel** — Deployment platform, if configured.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sandhya-it/SWYNEX-Responsive-Landing-Page.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SWYNEX-Responsive-Landing-Page
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Build the project for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
